# Project Notes

Research sprint for Candidate-Set Selector Switching / answer-cluster ranking on repeated-sampling traces. This is not a packaged repo yet; it is a local lab with runnable Python scripts in `work/`, generated reports in `outputs/`, and large Monkey Business JSONs in `work/`.

## Layout

- `work/*.py`: source scripts. Prefer editing these first.
- `outputs/*.py`: copied script snapshots from prior runs, plus generated CSV/Markdown/SVG outputs.
- `work/GSM8K_Llama-3-8B-Instruct.json`, `work/MATH_Llama-3-8B-Instruct.json`, `work/MATH_Gemma-2B.json`, `work/MATH_Pythia-1B.json`: large local trace files from `ScalingIntelligence/monkey_business`.
